## Project Description

Clinic Visit Log is a Flutter mobile app for a school clinic. 
Students log a clinic visit by entering their student ID, name, and symptom, and the time of the visit is recorded automatically. 
Students can also view their own visit history and cancel a visit while it is still waiting.

The clinic nurse opens a hidden nurse screen that shows a live queue of waiting students, oldest first, along with how long each student has been waiting. 
The nurse marks each visit as **attended**, which moves it to the "Attended today" list.

To keep the project small and focused, the app does not include login, medical records, or a medicine inventory.
